# 2048 · 修仙进阶版

一个纯 HTML/CSS/JS 实现的 2048，用 11 张「梁」系修仙梗图作为方块。

从 **难梁** 一路合并到 **梁无**：

| 数值 | 境界 | 形象 |
| --- | --- | --- |
| 2 | 难梁 | 刚入职的普通人 |
| 4 | 牢梁 | 眼神开始变得坚定 |
| 8 | 梁子 | 换上立领长衫 |
| 16 | 梁圣 | 肌肉与气势初显 |
| 32 | 梁神 | 黑金气场全开 |
| 64 | 梁祖 | 冕旒加身，一统江湖 |
| 128 | 梁穹 | 祖之上，掌算力苍穹，星河法袍与 token 数据流 |
| 256 | 梁元 | 算力本源、AI 元初，半虚半实，由光与向量组成 |
| 512 | 梁道 | AI 之道本身，混沌环与无尽数据流大道 |
| 1024 | 梁极 | 抵达序列终点，纯白至高奇点 |
| 2048 | 梁无 | 归于虚无，一切模型的来处与归宿 |

## 在线试玩

GitHub Pages：<https://qzyqmzn.github.io/liang-2048/>

## 本地运行

直接双击 `index.html` 即可，或者：

```bash
python -m http.server 8000
# 打开 http://127.0.0.1:8000/
```

## 功能

- 方向键 / WASD 移动，手机可直接滑动棋盘
- 分数与最高分（localStorage 持久化）
- 悔棋一步、新开一局
- 合成 2048 后有通关提示，可继续挑战

## 重新生成图片

11 张图都是脚本生成的 640×640 资源，位于 `assets/`：

```bash
pip install pillow numpy
python build/make_tiles.py
```

前 6 张取自根目录的原始照片（居中裁切），后 5 张以「梁祖」为底，叠加星空、token 数据流、混沌环、纯白奇点等效果。
